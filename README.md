# TCWD AquaStat — Water Supply Forecasting & Decision Support System

AquaStat is an enterprise water utility forecasting, non-revenue water (NRW) management, and pump scheduling optimization platform built for Tabaco City Water District (TCWD).

## Architecture

- **Frontend**: React 18, Vite, Tailwind CSS, Recharts, Radix UI, Lucide Icons, Motion.
- **Backend API**: Node.js, Express, TypeScript, PostgreSQL.
- **Intelligence & Machine Learning**: Python (LSTM, SARIMAX, Isolation Forest, Constrained Optimization).

## Getting Started

### 1. Frontend Development Server

```bash
npm install
npm run dev
```

The frontend runs at [http://localhost:5173](http://localhost:5173).

### 2. Backend API Server

```bash
cd aquastat-backend
npm install
npm run dev
```

The backend API runs at [http://localhost:8000](http://localhost:8000).
